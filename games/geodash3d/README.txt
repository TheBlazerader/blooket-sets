GEOMETRY DASH 3D - OFFLINE PACKAGE

CONTENTS
- cl3dash_offline.html: offline game page
- Build/: the Unity WebGL game files supplied in geodash3d.zip
- style.css: local page styling

WINDOWS
1. Extract this entire ZIP into one folder.
2. Double-click START SERVER.bat.
3. In the browser, open http://localhost:8000/cl3dash_offline.html
4. Keep the server window open while playing.

CHROMEBOOK (Linux environment)
1. Extract the ZIP into a folder in your Linux files.
2. Open the Linux Terminal and cd into that folder.
3. Run: python3 -m http.server 8000
4. In Chrome, open: http://localhost:8000/cl3dash_offline.html
5. Keep the terminal open while playing.

IMPORTANT
- Do not open the HTML by double-clicking it. Unity WebGL needs to be served over HTTP.
- Once this package is extracted, the game assets load from this folder and do not need the internet.
- Yandex ads, purchases, cloud saves, and online leaderboards are disabled in this offline wrapper.
